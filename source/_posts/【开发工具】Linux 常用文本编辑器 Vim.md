Vim（Vi IMproved）是 Linux/Unix 系统下最流行的文本编辑器之一，是从经典的 Vi 编辑器发展而来的增强版本。

|  特性  |             说明             |
| :--: | :------------------------: |
|  全称  |    Vi IMproved（Vi 的增强版）    |
| 设计哲学 |      模式化编辑、键盘驱动、命令组合       |
| 核心优势 |    无需鼠标、高效快捷、轻量级、可高度定制     |
| 适用场景 | 代码编写、配置文件修改、远程服务器编辑、日常文本处理 |

Vim 的设计理念是**命令的组合**。用户学习了各种文本间移动、跳转和编辑的命令后，能够灵活组合使用，实现比普通编辑器更加高效的文本编辑。

## 一、Vim 的核心模式

Vim 是一款**多模式编辑器**，这是它与其他编辑器最根本的区别。Vim 共有 12 种模式，其中最常用的是以下三种：

|                 模式                 |         功能描述         |         进入方式          |                退出方式                |
| :--------------------------------: | :------------------: | :-------------------: | :--------------------------------: |
|         普通模式（Normal Mode）          | 执行光标移动、删除、复制、粘贴等编辑命令 |     打开 Vim 时默认进入      | 按 `i`、`a`、`o` 等进入插入模式；按 `:` 进入底行模式 |
|         插入模式（Insert Mode）          |    正常输入文本，类似普通编辑器    | 普通模式下按 `i`、`a`、`o` 等  |          按 `Esc` 键返回普通模式           |
| 底行模式（Command Mode / Lastline Mode） |   执行保存、退出、查找、替换等命令   | 普通模式下按 `:`（Shift + ;） |           执行命令后自动返回普通模式            |

三种模式的关系如下图所示：

```text
+---------------+
|   底行模式 :    |  ←  输入 :w、:q、:%s 等命令
|   (Command)  |
+---------------+
       ▲
       │ Esc
       ▼
+---------------+
|   普通模式      |  ←  默认模式，浏览/编辑指令
|   (Normal)     |
+---------------+
       ▲
       │ i / a / o
       ▼
+---------------+
|   插入模式      |  ←  正常输入文本
|   (Insert)       |
+---------------+
```

### 1 普通模式（Normal Mode）

普通模式是 Vim 的默认模式，也是所有编辑命令的入口。在此模式下，键盘上的按键不再是输入字符，而是执行各种编辑命令。例如：
- `h`、`j`、`k`、`l` 控制光标移动
- `dd` 删除整行
- `yy` 复制整行
- `p` 粘贴

### 2 插入模式（Insert Mode）

插入模式是我们进行文本编辑时最频繁使用的模式。在该模式下，从键盘输入的所有字符都会被插入到当前缓冲区中，操作方式与记事本等普通文本编辑器完全类似。进入插入模式后，编辑器左下角会显示 `-- INSERT --` 提示。

### 3 底行模式（Command Mode / Lastline Mode）

底行模式用于执行文件的保存、退出、搜索、替换等高级操作。进入底行模式后，屏幕底部会出现一个冒号（`:`），用户需要在该命令行中输入指令。执行命令后按回车键确认。

### 4 可视模式（Visual Mode）

除了上述三种主要模式，Vim 还提供了**可视模式**（Visual Mode），用于选择和操作文本块：

|     命令     |       功能        |
| :--------: | :-------------: |
|    `v`     | 进入字符可视模式（按字符选择） |
|    `V`     |  进入行可视模式（按行选择）  |
| `Ctrl + v` |  进入块可视模式（按列选择）  |

进入可视模式后，编辑器左下角会显示 `-- VISUAL --` 提示。在该模式下选择文本后，复制（`y`）、删除（`d`）、替换等命令仅作用于选中的文档。

## 二、启动与退出 Vim

### 1 启动 Vim

|       命令        |       说明        |           示例           |
| :-------------: | :-------------: | :--------------------: |
|    `vim 文件名`    |     打开或创建文件     |     `vim test.txt`     |
|  `vim +n 文件名`   |  打开文件并定位到第 n 行  |   `vim +10 test.txt`   |
| `vim +/关键字 文件名` | 打开文件并高亮首个匹配的关键字 | `vim +/error test.txt` |

```bash
# 打开 test.txt 文件
vim test.txt

# 打开文件并跳转到第 10 行
vim +10 test.txt

# 打开文件并搜索 "error"
vim +/error test.txt
```

### 2 保存与退出

在底行模式下执行以下命令：

|         命令          |    说明     |
| :-----------------: | :-------: |
|        `:w`         |   保存文件    |
|        `:q`         |  退出 Vim   |
| `:wq` 或 `:x` 或 `ZZ` |   保存并退出   |
|        `:q!`        | 强制退出（不保存） |
|       `:wq!`        |  强制保存并退出  |

## 三、普通模式下的光标移动

普通模式下，Vim 提供了一套完整的键盘移动方案，无需使用鼠标或方向键。

### 1 基本移动

| 命令  |     说明     |
| :-: | :--------: |
| `h` | 光标向左移动一个字符 |
| `j` |  光标向下移动一行  |
| `k` |  光标向上移动一行  |
| `l` | 光标向右移动一个字符 |

### 2 行内移动

|    命令     |      说明       |
| :-------: | :-----------: |
| `0` 或 `^` |     移动到行首     |
|    `$`    |     移动到行尾     |
|    `w`    |  跳到下一个单词的开头   |
|    `e`    | 跳到当前或下一个单词的结尾 |
|    `b`    |  回到上一个单词的开头   |

### 3 页面移动

|     命令      |    说明     |
| :---------: | :-------: |
|    `gg`     | 移动到文件第一行  |
|     `G`     | 移动到文件最后一行 |
| `nG` 或 `:n` | 移动到第 n 行  |
| `Ctrl + f`  |   向下翻一页   |
| `Ctrl + b`  |   向上翻一页   |
| `Ctrl + d`  |   向下翻半页   |
| `Ctrl + u`  |   向上翻半页   |

## 四、普通模式下的文本编辑

### 1 进入插入模式

| 命令  |      说明      |
| :-: | :----------: |
| `i` |  在光标当前位置前插入  |
| `a` |  在光标当前位置后插入  |
| `I` |   在当前行行首插入   |
| `A` |   在当前行行尾插入   |
| `o` | 在当前行下方新开一行插入 |
| `O` | 在当前行上方新开一行插入 |

### 2 删除操作

|     命令     |      说明       |
| :--------: | :-----------: |
|    `x`     |  删除光标所在位置的字符  |
|    `nx`    | 删除光标开始的 n 个字符 |
|    `X`     |   删除光标前一个字符   |
|    `dd`    |     删除当前行     |
|   `ndd`    | 删除从当前行开始的 n 行 |
|    `dw`    | 删除从光标位置到单词末尾  |
| `d$` 或 `D` |  删除从光标位置到行尾   |

### 3 复制与粘贴

|  命令   |      说明       |
| :---: | :-----------: |
| `yy`  |     复制当前行     |
| `nyy` | 复制从当前行开始的 n 行 |
| `yw`  |    复制一个单词     |
|  `p`  |   在当前行下方粘贴    |
|  `P`  |   在当前行上方粘贴    |
| `np`  |    粘贴 n 次     |

### 4 撤销与重做

|     命令     |    说明    |
| :--------: | :------: |
|    `u`     | 撤销上一步操作  |
| `Ctrl + r` | 重做（撤销撤销） |

### 5 替换

|   命令    |         说明          |
| :-----: | :-----------------: |
| `r 字符`  |   将光标所在字符替换为指定字符    |
| `nr 字符` | 将光标开始的 n 个字符替换为指定字符 |
|   `R`   |    进入替换模式（连续替换）     |
|   `~`   |    切换光标所在字符的大小写     |

## 五、底行模式下的常用操作

### 1 搜索

|   命令   |       说明        |
| :----: | :-------------: |
| `/关键词` |     向下搜索关键词     |
| `?关键词` |     向上搜索关键词     |
|  `n`   | 跳转到下一个匹配（普通模式下） |
|  `N`   | 跳转到上一个匹配（普通模式下） |

### 2 替换

|        命令         |            说明             |
| :---------------: | :-----------------------: |
|   `:s/old/new/`   |    将当前行第一个 old 替换为 new    |
|  `:s/old/new/g`   |    将当前行所有 old 替换为 new     |
|  `:%s/old/new/g`  |    将全文件所有 old 替换为 new     |
| `:n,ms/old/new/g` | 将第 n 行到第 m 行的 old 替换为 new |

示例：

```bash
# 将当前行第一个 "foo" 替换为 "bar"
:s/foo/bar/

# 将当前行所有 "foo" 替换为 "bar"
:s/foo/bar/g

# 将全文件所有 "foo" 替换为 "bar"
:%s/foo/bar/g

# 将第 10 到第 20 行的 "foo" 替换为 "bar"
:10,20s/foo/bar/g
```

### 3 显示行号

|              命令               |   说明   |
| :---------------------------: | :----: |
|   `:set nu` 或 `:set number`   |  显示行号  |
| `:set nonu` 或 `:set nonumber` | 取消显示行号 |

## 六、可视模式与批量操作

### 1 可视模式的基本使用

|     命令     |      说明      |
| :--------: | :----------: |
|    `v`     |   进入字符可视模式   |
|    `V`     |   进入行可视模式    |
| `Ctrl + v` | 进入块可视模式（列模式） |

进入可视模式后，使用移动命令（`h`、`j`、`k`、`l` 等）选择文本，然后执行操作：
- `d`：删除选中的文本
- `y`：复制选中的文本
- `>`：向右缩进选中的文本
- `<`：向左缩进选中的文本

### 2 批量注释（块可视模式）

使用块可视模式可以快速为多行代码添加注释：

```bash
# 1. 按 Ctrl + v 进入块可视模式
# 2. 使用上下键选中多行
# 3. 按 Shift + i 进入插入模式，输入注释符号（如 //）
# 4. 按 Esc，Vim 会自动在每一行前插入 //
```

示例效果：

```text
修改前：          修改后：
int a = 1;        // int a = 1;
int b = 2;        // int b = 2;
int c = 3;        // int c = 3;
```

|    `Ctrl + w + w`    |    在分屏间切换    |

|     `gT`      | 切换到上一个标签页 |
|  `:tabclose`  |  关闭当前标签页  |

### 3 多文件切换

|   命令    |    说明    |

|  `:n`   | 切换到下一个文件 |

## 八、宏录制

Vim 支持宏录制功能，可以录制一系列操作并重复执行，非常适合批量处理重复性任务。

|    命令    |           说明            |
| :------: | :---------------------: |
| `q 寄存器名` | 开始录制宏（如 `qa` 录制到寄存器 a）  |
|   `q`    |          结束录制           |
| `@ 寄存器名` | 播放宏（如 `@a` 播放寄存器 a 中的宏） |
|   `@@`   |        重复上一次播放的宏        |

## 九、.vimrc 配置文件

Vim 通过 `~/.vimrc` 文件进行个性化配置。该文件使用 Vimscript 语言编写，在 Vim 启动时自动加载。

### 1 常用配置项

|         配置项          |     说明     |
| :------------------: | :--------: |
|     `set number`     |    显示行号    |
| `set relativenumber` |   显示相对行号   |
|   `set cursorline`   |   高亮当前行    |
|   `set tabstop=4`    | 设置制表符宽度为 4 |
|   `set expandtab`    | 将制表符转换为空格  |
|   `set autoindent`   |   启用自动缩进   |
|    `set hlsearch`    |   高亮搜索结果   |
|   `set incsearch`    |   启用增量搜索   |
|     `syntax on`      |   启用语法高亮   |

### 2 配置示例

创建或编辑 `~/.vimrc` 文件：

```bash
vim ~/.vimrc
```

添加以下常用配置：

```vim
" 显示设置
set number              " 显示行号
set relativenumber      " 显示相对行号
set cursorline          " 高亮当前行

" 缩进设置
set tabstop=4           " 制表符宽度
set shiftwidth=4        " 缩进宽度
set expandtab           " 将制表符转为空格
set autoindent          " 自动缩进

" 搜索设置
set hlsearch            " 高亮搜索结果
set incsearch           " 增量搜索
set ignorecase          " 搜索忽略大小写
set smartcase           " 智能大小写（混合时区分）

" 语法高亮
syntax on

" 颜色方案
colorscheme default
```

## 十、常用插件

Vim 支持通过插件管理器扩展功能。以下是常用的插件管理器及推荐插件。

### 1 Vim-Plug 安装

```bash
curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

### 2 在 .vimrc 中配置插件

```vim
call plug#begin('~/.vim/plugged')

" 文件树导航
Plug 'preservim/nerdtree'

" Git 集成
Plug 'tpope/vim-fugitive'

" 状态栏增强
Plug 'vim-airline/vim-airline'

" 语法检查
Plug 'vim-syntastic/syntastic'

call plug#end()
```

配置完成后，在 Vim 中执行 `:PlugInstall` 安装插件。
